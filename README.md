# Debanjan Majumder — Developer Portfolio

Personal software developer portfolio website showcasing engineering projects, academic background, technical skills, and experience.

Built with clean, modern vanilla web standards — featuring custom glassmorphism design tokens, an interactive Canvas 2D background engine, smooth scroll kinematics, and a dynamic morphing capsule navbar.

🌐 **Live Demo:** [Portfolio on GitHub Pages](https://debanjan-21.github.io/Portfolio/) *(or hosted URL)*  
📄 **Featured Project:** [AI Resume Analyzer & ATS Optimizer](https://github.com/Debanjan-21/AI-Resume-Analyzer)

---

## ⚡ Tech Stack & Architecture

- **Markup & Semantics:** HTML5, Accessible ARIA standards
- **Styling & Effects:** Modern CSS3 (CSS Variables, Glassmorphism, Backdrop Blur Filters, Keyframe Animations, Responsive Flexbox & Grid)
- **Interactive Background:** Canvas 2D API (`background.js`) with multi-layered particle physics, reactive mouse repulsion, pulsating circuit traces, and neural network graphs
- **UX & Interactions:** Vanilla ES6+ (`script.js`) with IntersectionObserver section tracking, 3D card tilt physics, auto-typing simulation, and cubic bezier smooth scroll navigation

---

## 🚀 Key Features

- **Dynamic Morphing Capsule Navbar:** Fixed navigation pill that automatically collapses to the active section name on scroll and smoothly expands back on hover.
- **Interactive Multi-layer Canvas:** Ambient glowing orbs, drifting code badges, and scroll-scrubbed interactive visual scenes.
- **3D Interactive Profile Tilt:** Responsive 3D parallax tilt reacting to cursor coordinates over the avatar card.
- **Featured Projects Showcase:** Highlighted cards featuring live GitHub repositories, tech stacks, and feature breakdowns (including [AI Resume Analyzer & ATS Optimizer](https://github.com/Debanjan-21/AI-Resume-Analyzer)).
- **Translucent Loader:** Elegant loading screen with dynamic progress bar and timed exit transitions.
- **Full Responsive Design:** Tailored layouts across ultra-wide desktops, laptops, tablets, and mobile devices.

## 🛠️ Local Development & Preview

No build step or package installation is required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Debanjan-21/Portfolio.git
   cd Portfolio
   ```

2. **Run locally:**
   - Using VS Code: Right-click `index.html` and select **Open with Live Server**.
   - Using Python:
     ```bash
     python -m http.server 8000
     ```
   - Or simply double-click `index.html` in your file browser.
